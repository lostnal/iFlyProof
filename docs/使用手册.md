# iFlyProof 使用手册

本文面向日常使用者，按“从打开到导出”的顺序说明每个功能。开发/部署相关内容见 [开发文档](开发文档.md)。

---

## 一、启动

**macOS**：双击 **`iFlyProof.command`**；
**Windows**：双击 **`iFlyProof.bat`**。

浏览器会自动打开工作台，不需要命令行。

- 停止（macOS）：双击 `stop-iFlyProof.command`；
- 第一次打开如果 macOS 提示“无法验证开发者”，在文件上右键 → 打开，或到“系统设置 → 隐私与安全性”里允许。

命令行方式（备选）：

```bash
python3 server.py
```

如果部署在另一台机器（如 NAS），把 `127.0.0.1` 换成那台机器的地址，并确保启动时设置了 `HOST=0.0.0.0`。

## 二、首页

首页只有一个目标：**把讯飞听见的链接变成可编辑的稿子**。

### 1. 输入链接

把讯飞听见的分享链接粘贴到输入框，点 **“解析并打开”**。

- 支持 `https://shareaudio.iflyrec.com/appShare/share.html?audioId=...` 这类分享链接；
- 解析时会联网访问讯飞，需要网络；
- 分享链接有有效期，过期后需要重新生成。

### 2. 多个链接（录音笔分段）

讯飞录音笔长时间录音会自动切成多段、生成多个分享链接。点输入框右侧的 **“＋”** 可以最多添加 **3 个链接**：

- 第二、第三个链接会拼在第一个后面；
- 时间轴自动接续：第二段从第一段结束的时间开始；
- 音频会下载并拼接成一条，进度显示在编辑页底部。

> 只有整段录音的第一段需要手动添加，后面的按顺序点“＋”粘贴即可。

### 3. 历史链接

首页的 **“历史链接”** 会列出最近 **10 个**用过的链接。

- 点某一条即可重新打开；
- 如果这个链接之前保存过本地数据，会弹窗 **“已为您加载历史数据”**，直接进入编辑界面，**不会重新解析**；
- 如果只是用过但没有保存过数据，会正常解析一次。

### 4. 打开项目

点 **“打开项目”**，选择之前保存的 `.trp` 文件，即可恢复完整的文字、说话人、编辑记录和音频。

### 5. 继续编辑

如果浏览器里有上次未完成的稿子，首页会出现 **“继续编辑”**，点击即可恢复。

## 三、编辑页

### 顶部工具栏

从左到右依次是：

| 按钮 | 作用 |
| --- | --- |
| 撤销 | 撤销上一步（分段、删除、改字、改发言人、替换等） |
| 分段 | 进入分段模式，在一句里选中文字，从选区起点拆成两句 |
| 自动分说话人 | 用本地 AI 按声音把条目分给不同说话人（见下文） |
| 保存项目 | 下载 `.trp` 项目文件（文字 + 音频） |
| 打开项目 | 打开 `.trp` 项目文件 |
| 导出文本 | 下载 `[时间] 发言人：文字` 格式的 `.txt` |
| 返回首页 | 回到首页，**不会清空**当前稿子 |

### 正文区

- 每行是一条转写：时间、发言人、文字；
- 点**某个字**：音频跳到该字前约 1 秒（按字数比例估算）；
- 点时间/发言人/行空白：跳到该句开头；
- **双击某个字**：进入编辑，光标落在该字后面；
- 行尾的 **✎**：编辑这一行；
- **右键**：编辑文字 / 编辑发言人 / 删除 / 复制本行 / 复制所选。

### 右侧说话人对照

- 每个说话人一行：标识 + 别名输入框 + “替换” + “刷”；
- 输入别名后点 **“替换”**（或回车）：左侧所有这个说话人同步改成别名；
- 点 **“刷”**：在左侧拖选一片，把这片发言人刷成这个人；
- **“刷新说话人”**：按当前显示名归并、去重（适合改名改乱后清理）；
- **“恢复到讯飞原有版本”**：重新拉取讯飞原始数据，覆盖当前修改（会二次确认）。

## 四、播放与定位

- 底部播放器：播放/暂停、前进/后退 5 秒、进度条、倍速；
- 拖进度条：文字会自动滚到对应行并高亮；
- 空格键：播放/暂停（不在输入框里时）；
- 左右方向键：前进/后退 5 秒（不在输入框里时）。

---

## 五、编辑操作

### 改文字

双击文字，或点行尾 ✎。改完点空白处/回车结束；`Esc` 取消。

### 改发言人

双击发言人标签，输入新名字回车。

- 输入一个**新名字**：会在右侧新增一个说话人；
- 输入**已有名字**：会归到那个说话人；
- 也可以用右侧的“替换”统一改名。

### 分段

1. 点 **“分段”**；
2. 在任意一句里**选中要拆开的位置**；
3. 松手后，从选区起点拆成两句，时间按字数比例分配。

### 删除

- 右键 → 删除；
- 或拖选多行后，底部点 **“删除 N 项”**。

### 撤销

- 工具栏 **“撤销”**；
- 快捷键 **Ctrl+Z / ⌘+Z**。

> 撤销是整体回退，最多保留 80 步；在输入框里按 Ctrl+Z 走浏览器自己的撤销。

## 六、多选、复制与批量删除

不需要先开“批量模式”：

1. 在任意一行上**按住鼠标往下拖**；
2. 经过的行会被选中（拖到列表边缘会自动滚动）；
3. 底部出现操作条：

| 按钮 | 作用 |
| --- | --- |
| 复制所有信息 | 复制 `[时间] 发言人：文字`，一行一条 |
| 仅复制内容 | 只复制正文文字 |
| 删除 N 项 | 删除选中的条目 |
| 取消 | 清空选择 |

> 在文字区域里拖动仍然可以选中文字，用于分段/格式刷；编辑中的行不会触发框选。

---

## 七、自动分说话人

适合“事先不知道有几个人、只想快速分一下”的场景。

1. 点 **“自动分说话人”**；
2. **首次使用**会自动准备本地环境（约 1–2 分钟，底部显示进度），完成后自动继续；
3. 输入预计人数（2–10）；
4. 输入只分析前多少分钟（`0` = 全部；建议先用 2–5 分钟试跑）；
5. 确认后会覆盖当前发言人标注；
6. 完成后条目会标成“说话人 1/2/3…”，到右侧改成真实姓名即可。

说明：

- 全程本地 CPU 运行，不上传音频；
- 第一次运行需要加载模型，之后会快一些；
- 3 小时音频通常需要几分钟；
- 只处理前 N 分钟时，后面的条目保持原样。

## 八、保存与打开项目

### 保存项目

点 **“保存项目”**，会生成一个 **`.trp`** 文件：

- 内部是一个 zip，含 `state.json`（全部文字/说话人/时间）和 `audio.mp3`（音频）；
- 文件名默认用稿子标题；
- 改后缀为 `.zip` 也能用解压工具打开查看。

### 打开项目

点 **“打开项目”**，选择 `.trp` 文件，恢复全部内容。

> `.trp` 是最好的备份方式：换电脑、清浏览器数据都不怕。

---

## 九、导出文本

点 **“导出文本”**，下载 `标题.txt`，格式：

```
[00:12:34] 说话人1：这段文字……
[00:12:41] 说话人2：这段文字……
```

可直接粘到 Word / 企业微信 / 邮件里。

---

## 十、数据与隐私

- 转写稿保存在浏览器 `localStorage`（自动保存，无需手动点保存）；
- 音频缓存在浏览器 `IndexedDB`，同一链接再次打开会直接用缓存；
- 服务端**不保存**用户内容，只做静态文件、讯飞解析和音频代理；
- 清浏览器站点数据会丢失本地记录，重要稿件请用 `.trp` 备份；
- 不要把真实会议内容提交到公开仓库。

| 快捷键 | 作用 |
| --- | --- |
| `空格` | 播放 / 暂停（不在输入框时） |

## 十二、常见问题

**导入后没有声音？**
检查分享链接是否过期；或看底部是否还在“下载音频”。

**说话人分得不准？**
自动分离只是初筛，最终以人工改名为准；可以先少量试跑，确认人数设置合理。

**换电脑后历史没了？**
历史记录在浏览器本地，不跨设备；用 `.trp` 迁移。

**能不能多人同时编辑同一份？**
当前是“各自本地”的设计，不提供多人协作；多人使用请各自打开、各自保存。
