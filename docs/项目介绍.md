# iFlyProof 项目介绍

## 一句话

**iFlyProof 是一个本地运行的讯飞听见转写稿校对工作台：粘贴分享链接，就能边听边改、整理说话人、导出干净文本。**

英文 tagline：*A local-first transcript proofing workbench for iFlytek Recorder shares.*

---

## 一段话

讯飞听见的分享页能看文字、能听录音，但很难真正“改稿”。iFlyProof 把分享链接变成一个可编辑的工作台：点文字跳播放、双击改错字、拖选批量删、按声音自动分说话人，最后导出成干净的文本或一个带音频的项目文件。全程在浏览器和本机完成，不上传云端，不需要账号和数据库。

---

## 完整介绍

### 为什么做这个

日常会议、访谈、培训大量用讯飞听见转写。讯飞给出的分享页可以看、可以听，但**不能真正编辑**：改错字、调说话人、删口水话、把录音笔自动切分的几段拼成一份完整稿，都做不了。只能导出 Word 再对着时间轴手工改，非常低效。

也找过市面上的替代方案，结论是**没有特别合适的**：

- 在线转写平台大多要求把音频重新上传到云端，费流量、有隐私顾虑，时间码还和讯飞原稿对不上；
- 专业字幕/转写软件功能很重，学习成本高，对“中文会议 + 讯飞分享链接”这个场景并不顺手；
- 通用音频软件只能听，不能改文字；
- 自己写脚本，又很难做到“点文字跳播放、拖进度条反查文字”这种顺手的交互。

所以做了 iFlyProof：**不重新转写、不上传云端，只把讯飞的分享稿变成一份可以认真校对的工作稿。**

### 它能做什么

- **导入**：粘贴讯飞听见分享链接，自动拿到文字与时间码；
- **多段拼接**：最多 3 个链接，第二段起时间轴自动接续（适配录音笔 4 小时自动分段）；
- **边听边改**：点文字跳到对应位置，拖进度条反查文字，双击就地改；
- **说话人**：点标签改名/新建，框选多行后“设为”批量归属，右侧输入框批量改名；
- **批量操作**：按住鼠标拖选多行，复制全部信息 / 仅复制内容 / 删除；
- **自动分说话人**（可选）：本地 CPU 跑 sherpa-onnx + CAM++，不上传音频；
- **不怕丢**：自动保存到浏览器，重要稿件可导出 `.trp` 项目文件（文字 + 音频）；
- **导出**：`[时间] 发言人：文字` 格式的 TXT，直接粘进 Word/邮件。

### 适合谁

- 经常用讯飞听见/录音笔做会议纪要、访谈整理、培训记录的人；
- 需要精校转写稿，又不想把音频传到第三方平台的人；
- 希望有一个“打开就能用、不用装重型软件”的本地工具的人。

### 技术特点

- **零外部 Web 依赖**：Python 标准库后端 + 单文件 `index.html` 前端，`git clone` 后双击即可运行；
- **本地优先**：转写稿在浏览器 `localStorage`，音频在 `IndexedDB`，服务端不保存用户内容；
- **可替换**：解析、音频、说话人分离三层解耦，方便接入其他转写源；
- **开源**：MIT License。

### 项目状态

早期版本（v0.1.0），已经能完整走通“导入 → 校对 → 整理说话人 → 导出/保存”的流程。欢迎试用、提 issue、一起完善。
